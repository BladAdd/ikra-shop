# Инструкция: админка магазина «Икра & Рыба»

Адрес админки: **https://bladadd.github.io/ikra-shop/admin.html**
Всё, что вы меняете в админке, попадает на сайт само: сохранение обновляет каталог, и через 1–2 минуты сайт показывает новое. Программист не нужен.

---

## 1. Как войти

Три способа входа:

1. **Токен GitHub (основной).** Токен — это «пароль», который разрешает админке сохранять файлы в вашем репозитории.
   - Зайдите на github.com → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
   - Название: любое («ikra-admin»). Срок: год (потом выпустите новый).
   - Repository access: **Only select repositories** → выберите репозиторий со сайтом.
   - Permissions → Repository permissions → **Contents: Read and write**. Остальное не нужно.
   - Generate token → скопируйте длинную строку → вставьте в поле входа админки.
   - Токен запоминается в браузере: второй раз вводить не нужно. Он хранится только у вас и даёт доступ только к этому репозиторию — никому его не передавайте.
2. **Google** — кнопка «Войти через Google» (полноценно заработает после запуска сервера заказов).
3. **Локальный режим** — если сервер заказов запущен на вашем компьютере. Для повседневной работы не нужен.

## 2. Обзор (первый экран)

Шесть карточек-показателей: сколько товаров, сколько **без фото** (клик — откроет список ждущих фото), категорий, товаров «по запросу», активных промокодов, дата последнего обновления каталога. Ниже — быстрые действия: добавить товар, загрузить фото, открыть сайт, прайс (CSV), копия каталога (JSON).

## 3. Товары: поиск, правка цены, фасовки

- **Поиск** — по названию и тегам. Фильтр — по категории. Чипы: «Все / Нет фото / По запросу / Со скидкой / С плашкой».
- **Изменить цену** — кликните по цене прямо в списке, введите новую, Enter (Esc — отмена). «По запросу» — если цену не указывать.
- **Фасовки** — откройте товар. В модалке блок «Фасовки»: вес / цена / всего / галочка «основная».
  - «Всего» считается само: у весовых (кг) — цена за кг × вес; у порционных — цена упаковки.
  - **Основная фасовка** — та, что показывается крупной ценой в каталоге.
  - «+ фасовка» добавляет строку (например «3 кг» — выгоднее за килограмм).
  - Флажок «Порционный товар» — для позиций, которые продаются упаковкой (банка, набор), а не на вес.
- **Старая цена** — для зачёркивания (скидка). Бейджи — «Хит / Новинка / Премиум».

## 4. Мультивыбор (массовые операции)

Поставьте галочки на товарах (или «☑ Все» в категории) — появится панель:
- **Цена +N%** — поднять/снизить цены на процент (вместе с фасовками). 5 → +5%, −5 → скидка 5%. Перед массовым изменением сверьтесь с прайсом поставщика!
- Поставить/снять плашки (Хит, Новинка, Премиум) сразу многим.
- **Перенести в категорию** — переместить выбранные товары.
- **Удалить** — с подтверждением. Внизу на 8 секунд появится тост **«Вернуть»** — жмите, если передумали (работает и после сохранения).

## 5. Фото (главный раздел для запуска)

Сейчас 120 из 147 товаров ждут фото. Два способа:

1. **Ассистент «Фото → товар»:** нажмите «Загрузить фото» и выберите сразу много файлов (названия файлов лучше совпадают с товаром: `skumbriya-goryachego-kopcheniya.jpg`). Ассистент сам предложит до 3 подходящих товаров — проверьте и подтвердите. Фото сожмётся и привяжется к товару автоматически.
2. **Раздел «Нужны фото»** — список всех товаров с заглушками; кнопка у каждого открывает выбор файла сразу для него.

В **галерее** видно каждое фото: используется и у какого товара. «Привязать…» — к другому товару; «Удалить» — только неиспользуемые. Заглушку `__NEED_PHOTO__.jpg` удалить нельзя — это служебный маркер «фото появится».

**Правило:** не переименовывайте фото в репозитории вручную — привязка идёт через админку.

## 6. Категории

Порядок — перетаскиванием или стрелками ↑↓. **Код** категории (латиница, например `gifts`) менять не рекомендуется — на него завязаны ссылки; админка предупредит и попросит подтверждение. Новая категория: название + подзаголовок + код.

## 7. Промокоды

Карточка «Промокоды» в разделе «Магазин»: добавьте строку — код (например, ПРИВЕТ10), тип (проценты или фикс. сумма), размер скидки, минимальная сумма заказа, включён/выключен. Условия промокодов уже описаны в Публичной оферте (раздел 6) — оферту менять не нужно.

## 8. Прайс CSV

«Прайс CSV» (в Обзоре или Резервных копиях) скачивает файл «Категория;Товар;Фасовка;Цена;Единица» — по строке на каждую фасовку. Открывается в Excel.

## 9. Сохранение на сайт

Это главная кнопка. Пока не нажали — изменения видны только вам.

- Сверху счётчик несохранённых изменений и **Ctrl+S** как быстрое сохранение.
- Сохранение делает два действия: обновляет каталог + резервную копию (прогресс показывается: «Сохраняю каталог… → Обновляю резервную копию…»).
- Сайт обновится через **1–2 минуты** (GitHub Pages собирается сам). Открытый сайт — обновите страницу.
- При попытке уйти с несохранёнными изменениями браузер спросит подтверждение.

## 10. Заказы

Вкладка «Заказы» (заработает с запуском сервера): статус, состав, суммы, фильтры. Новый заказ — «ожидает»: свяжитесь с покупателем, подтвердите вес весовых позиций (оффера позволяет +10%), отправьте ссылку на оплату или примите оплату при получении.

## 11. Магазин и реквизиты

Вкладка «Магазин»: название, телефон, WhatsApp, город, часы работы, **ИНН, ОГРНИП, название ИП** — реквизиты появятся в подвале сайта и в юридических страницах, как только заполните. Ещё не заполнено — см. ЧЕКЛИСТ-ЗАПУСКА-ВЛАДЕЛЬЦА.md.

**WhatsApp для заказов** — только цифры, без `+` и пробелов: `79619200292`.

## 12. Резервные копии

- **Скачать копию (JSON)** — весь каталог одним файлом. Раз в месяц не помешает, и обязательно перед большими правками.
- **Восстановить** — загрузить такой файл обратно.
- **Прайс CSV** — см. раздел 8.

## 13. Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| «Файл изменён другим окном» (422) | Открыта вторая вкладка админки или правки с другого устройства. Обновите страницу (F5) и повторите. |
| «Нет интернета или GitHub недоступен» | Проверьте сеть; правки не потерялись — нажмите «Сохранить на сайт» ещё раз. |
| Токен не подошёл (401) | Истёк срок — выпустите новый (раздел 1). |
| «Нет прав» | В токене нет `Contents: Read and write` — создайте новый. |
| Изменений нет на сайте | Подождите 2 минуты, обновите страницу. Проверьте, что нажали «Сохранить на сайт». |
| Случайно удалили товар | «Вернуть» в тосте (8 сек) — или отмените всё, не сохраняя, и обновите страницу. |
| Фото не грузится | Формат JPG/PNG/WebP, до 8 МБ; повторите — админка сама обновит подпись файла при повторе. |
