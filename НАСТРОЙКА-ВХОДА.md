# Настройка входа через Яндекс, VK и MAX

Вход на сайт работает тремя способами: **Яндекс ID**, **VK ID**, **MAX** — плюс обычная почта с паролем. Кнопки уже стоят на сайте. Чтобы вход заработал «по-настоящему», нужно один раз зарегистрировать приложение у каждого провайдера и вписать ключи в настройки сервера. Это бесплатно.

---

## 1. Как это устроено (коротко)

- Кнопки входа ведут на сервер магазина: `{APP_URL}/api/auth/яндекс|vk|max/start`.
- Провайдер показывает своё окно входа и возвращает покупателя на сервер: `{APP_URL}/api/auth/<провайдер>/callback`.
- Сервер проверяет ответ, создаёт/находит аккаунт и впускает покупателя.

Поэтому **перед настройкой провайдеров** на сервере должны быть правильно заданы две переменные:

```
APP_URL=https://адрес-вашего-сервера      # публичный адрес API (Railway/Render)
FRONTEND_URL=https://bladadd.github.io/ikra-shop
```

Callback-адреса, которые вы будете вписывать в кабинеты провайдеров:

| Провайдер | Callback URL |
|---|---|
| Яндекс | `{APP_URL}/api/auth/yandex/callback` |
| VK | `{APP_URL}/api/auth/vk/callback` |
| MAX | — (OAuth нет; вход через мини-приложение, см. раздел 4) |

---

## 2. Яндекс ID

1. Откройте **https://oauth.yandex.ru** → войдите своим Яндекс-аккаунтом → «Создать новое приложение».
2. Название: «Икра & Рыба» (любое понятное вам).
3. Платформа: **Веб-сервисы** → в «Redirect URI» впишите callback из таблицы выше; в «Доступные домены» — домен сервера.
4. Права (только эти, ничего лишнего):
   - **Доступ к логину, email** (`login:email`);
   - **Доступ к дате рождения, полу, аватару, имени** (`login:info` — имя и аватар для профиля).
5. Нажмите «Создать приложение» → появятся **ClientID** и **Пароль приложения** (Client secret).
6. Впишите в переменные окружения сервера:

```
YANDEX_CLIENT_ID=ваш-ClientID
YANDEX_CLIENT_SECRET=ваш-пароль-приложения
```

7. Приложение работает сразу после создания (у Яндекса нет долгой модерации для этих прав). Если Яндекс попросит «Отправить на модерацию» — это только для расширенных прав, для логина достаточно базовых.

## 3. VK ID

1. Откройте **https://id.vk.ru/about/business/go/** → войдите через **VK Бизнес ID**.
   (Важно: бизнес-профиль VK должен быть верифицирован — VK блокирует приложения у неверифицированных аккаунтов. Следуйте подсказкам кабинета.)
2. «Мои приложения» → «Добавить приложение»: название «Икра & Рыба», платформа **Web**, картинка — логотип магазина.
3. **Базовый домен**: домен вашего сервера (должен точно совпадать с доменом в redirect URL).
4. **Доверенный redirect URL**: callback из таблицы выше.
5. Тип приложения: **Конфиденциальное** (обмен кода происходит на нашем сервере).
   - VK попросит указать **IP-адреса сервера** (allowlist) — впишите публичный IP сервера Railway/Render.
   - Получите **сервисный ключ доступа (service_token)**.
6. В настройках приложения включите доступ **«Почта»** — по умолчанию он **выключен**, без него VK не отдаст e-mail покупателя (аккаунт всё равно создастся, но без почты).
7. Впишите в переменные окружения:

```
VK_CLIENT_ID=ID-приложения
VK_CLIENT_SECRET=защищённый-ключ
VK_SERVICE_TOKEN=сервисный-ключ-доступа
```

8. Технические детали (уже учтены в коде): OAuth 2.1 с PKCE (S256), обмен кода — строго `application/x-www-form-urlencoded` на `https://id.vk.ru/oauth2/auth`, профиль — `POST https://id.vk.ru/oauth2/user_info`. Лимиты: 120 000 запросов/сутки на приложение.

## 4. MAX (мессенджер)

> У MAX **нет** OAuth для сторонних сайтов — проверено по официальной документации dev.max.ru
> в ноябре 2026. Официальный способ один: **мини-приложение внутри MAX** + одноразовый код.
> Код уже готов на нашей стороне; от владельца требуется создать бота один раз.

1. Откройте платформу **https://business.max.ru/self** → зарегистрируйтесь (резиденты РФ;
   профиль ИП/самозанятого/юрлица) и верифицируйте его через Госуслуги или банк (T-Business ID, Alfa ID).
2. Создайте **чат-бота** («Чат-боты» → создать) — пройдите модерацию.
3. После модерации скопируйте **токен бота** (Чат-боты → Настройки → токен).
4. В настройках мини-приложения укажите URL страницы входа:
   `https://bladadd.github.io/ikra-shop/max-auth.html`
5. Впишите в переменные окружения сервера:

```
MAX_WEBAPP_TOKEN=токен-вашего-бота
MAX_BOT_LINK=ссылка-на-бота-в-MAX   # диплинк вида https://max.ru/имя-бота — виден покупателям
```

6. Как это работает для покупателя: в окне входа на сайте нажимает «MAX» → видит ссылку на наше
   мини-приложение → открывает его в MAX → страница показывает **6-значный код** (действует
   5 минут) → покупатель вводит код на сайте и входит. Профиль MAX не содержит e-mail — аккаунт
   создаётся по ID MAX; если покупатель позже зарегистрируется по почте с тем же e-mail... аккаунты
   свяжутся по имени/почте, если почта совпадёт (у MAX её нет, поэтому связка — только если покупатель
   сам укажет совпадающие данные).
7. Если MAX_WEBAPP_TOKEN не задан — кнопка MAX откроет подсказку «ссылку пришлёт поддержка»,
   Яндекс и VK продолжат работать. Страница max-auth.html вне MAX код не выдаёт (нет подписи).

---

## 5. Проверка после настройки

1. Перезапустите сервер. В логах должно быть:
   `[server] OAuth: Яндекс вкл, VK вкл, MAX вкл; RollyPay: ...`
2. Откройте сайт → «Войти» → нажмите «Яндекс» — откроется настоящая страница входа Яндекса.
3. Войдите — вас вернёт на сайт, в шапке появится ваш профиль (имя/аватар).
4. Повторите для VK и MAX.
5. Проверьте кабинет: «Мои заказы» открывается у вошедшего покупателя.

Если вход не сработал — смотрите адрес возврата в браузере:
- `?auth_error=state_mismatch` — просто повторите вход (ссылка устарела);
- `?auth_error=yandex_disabled` / `vk_disabled` / `max_disabled` — ключи провайдера не заданы на сервере;
- `?auth_error=yandex_failed` и т.п. — смотрите лог сервера (детальная причина пишется туда).

---

## 6. Безопасность

- Все ключи живут **только** в переменных окружения сервера (.env / панель Railway/Render). Не пересылайте их в чатах и не коммитьте в git.
- Секреты можно менять в любой момент — перезапуск сервера подхватывает новые.
- Пароль покупателя при входе через провайдеров не используется и не хранится; аккаунты, созданные через Яндекс/VK/MAX и по почте с одним e-mail, объединяются в один профиль автоматически.
