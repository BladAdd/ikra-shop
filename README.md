# Икра — сайт магазина

Сайт магазина красной и чёрной икры и копчёной рыбы: каталог, корзина,
оформление заказа, доставка по Москве и Московской области, отправка по России.

## Как это работает

Статический сайт: HTML + CSS + JavaScript, без сборки и без сервера.
Открывается как обычный файл `index.html` и разворачивается на GitHub Pages.

## Как добавить товар

Всё в одном файле — `assets/js/products.js`.

1. Откройте `assets/js/products.js`.
2. Найдите нужную категорию (`Икра`, `Копчёная рыба`, `Ещё к столу`).
3. Скопируйте любой блок `{ ... }` целиком, вставьте рядом и поменяйте значения.
4. Положите картинку в `assets/img/` и укажите её в поле `img`.

Поля товара:

| Поле | Что значит |
|---|---|
| `id` | уникальный код латиницей, без пробелов |
| `name` | название для покупателя |
| `weight` | фасовка: `"500 г"`, `"1 кг"` |
| `price` | цена числом. `null` — покажет «По запросу» |
| `oldPrice` | старая цена для зачёркивания или `null` |
| `unit` | `"шт"` или `"кг"` |
| `img` | путь к картинке |
| `badge` | плашка: `"Хит"`, `"Новинка"`, `"Премиум"` или `null` |
| `desc` | короткое описание |
| `tags` | слова для поиска по каталогу |

Новую категорию добавляют так же: новый блок `{ id, title, subtitle, items: [...] }`
в массив `CATALOG`.

## Настройки магазина

Там же, в `assets/js/products.js`, объект `SHOP`: телефон, WhatsApp, город,
условия доставки, часы работы, ИНН и ОГРНИП, ссылка на Ozon.
Пока реквизиты не заполнены, они просто не показываются в подвале.

## Оплата

Сейчас работает режим **«по ссылке»**: покупатель оформляет заказ, заказ уходит
менеджеру в WhatsApp, менеджер присылает персональную ссылку на оплату.

Чтобы включить онлайн-оплату картой, нужен счёт ИП в платёжном сервисе
(ЮKassa, CloudPayments, Робокасса) и серверная часть: секретные ключи нельзя
держать в файлах сайта. Настройки — объект `PAYMENTS` в `assets/js/products.js`.

## Приём заказов на почту

В `assets/js/products.js` есть `ORDER_ENDPOINT`. Если вписать туда адрес приёма
заявок (например, Formspree), заказы будут приходить и на почту, и в WhatsApp.

## Фото

Фотографии взяты из Wikimedia Commons со свободными лицензиями
(CC0, CC BY, CC BY-SA, Public domain). Список источников и лицензий —
`assets/img/credits.json`. Скрипты загрузки — в `tools/`.

Перед публикацией стоит заменить их на реальные фото товара.

## Локальный запуск

Просто откройте `index.html` в браузере. Либо поднимите локальный сервер:

```
python -m http.server 8000
```

и зайдите на `http://localhost:8000`.
