# Икра — сайт магазина

Сайт магазина красной и чёрной икры и копчёной рыбы: каталог, корзина,
оформление заказа, доставка по Москве и Московской области, отправка по России.

## Как это работает

Две части:

1. **Сайт** (`index.html`, `payment-*.html`, `admin.html`) — статика: HTML + CSS + JS.
   Разворачивается на GitHub Pages, работает и без сервера (заказ уходит в WhatsApp).
2. **Сервер** (`server/`) — Node.js + Express + SQLite (better-sqlite3).
   Хранит пользователей, заказы и платежи, принимает онлайн-оплату через RollyPay.
   Разворачивается на Railway / Render.

Если сервер недоступен, оформление заказа автоматически откатывается на WhatsApp —
сайт не «ломается».

## Возможности

| Функция | Как работает |
|---|---|
| Регистрация | Google OAuth или e-mail + пароль (bcrypt, 12 раундов) |
| Сессии | JWT в httpOnly-cookie, SameSite=None + Secure в проде |
| База данных | SQLite (WAL), файл на постоянном томе сервера |
| Заказы | Цены пересчитываются **на сервере** по `data/catalog.json` |
| Оплата | RollyPay: СБП, карты, крипта. Вебхук с HMAC-SHA256 |
| Админка | Вход через Google по списку `ADMIN_EMAILS`, раздел «Заказы» |

## Управление сайтом

Всё меняется через админ-панель — без программиста:

- **Панель:** https://bladadd.github.io/ikra-shop/admin.html
- **Инструкция:** [АДМИНКА-ИНСТРУКЦИЯ.md](АДМИНКА-ИНСТРУКЦИЯ.md)

Цены, фото, товары, категории, контакты и реквизиты правятся в панели
и сохраняются прямо в репозиторий. Сайт обновляется через 1–2 минуты.

Данные лежат в `data/catalog.json` — это единственный источник правды.
Ручная правка этого файла тоже работает, но панель удобнее.

> Ссылка «Управление» на сайте скрыта от покупателей. Чтобы она появилась,
> откройте главную страницу с параметром `?admin=1` — браузер запомнит это.
> Убрать ссылку обратно: очистить данные сайта в браузере.

## Как добавить товар вручную (если панель недоступна)

Всё в одном файле — `data/catalog.json`.

1. Откройте `data/catalog.json`.
2. Найдите нужную категорию (`Икра`, `Горячее копчение`, `Холодное копчение` и т. д.).
3. Скопируйте любой блок `{ ... }` целиком, вставьте рядом и поменяйте значения.
4. Положите картинку в `assets/img/` и укажите её в поле `img`.

Поля товара:

| Поле | Что значит |
|---|---|
| `id` | уникальный код латиницей, без пробелов |
| `name` | название для покупателя |
| `weight` | фасовка: `"500 г"`, `"1 кг"` |
| `price` | цена числом: за 1 кг у весовых, за упаковку у порционных. `null` — «По запросу» |
| `packs` | все фасовки из прайса: `[{weight, price, total}]` (необязательно) |
| `oldPrice` | старая цена для зачёркивания или `null` |
| `unit` | `"шт"` или `"кг"` |
| `img` | путь к картинке |
| `badge` | плашка: `"Хит"`, `"Новинка"`, `"Премиум"` или `null` |
| `desc` | короткое описание |
| `tags` | слова для поиска по каталогу |

Новую категорию добавляют так же: новый объект `{ id, title, subtitle, items: [] }`
в массив `catalog`.

## Настройки магазина

В `data/catalog.json`, объект `shop`: телефон, WhatsApp, город,
условия доставки, часы работы, ИНН и ОГРНИП, ссылка на Ozon.
Пока реквизиты не заполнены, они просто не показываются в подвале.

## Оплата

Сейчас работает режим **«по ссылке»**: покупатель оформляет заказ, заказ уходит
менеджеру в WhatsApp, менеджер присылает персональную ссылку на оплату.

Чтобы включить онлайн-оплату картой, нужен счёт ИП в платёжном сервисе
(ЮKassa, CloudPayments, Робокасса) и серверная часть: секретные ключи нельзя
держать в файлах сайта. Настройки — блок `payments` в `data/catalog.json`
или вкладка «Оплата» в админке.

## Приём заказов на почту

В админке, вкладка «Оплата», поле «Адрес приёма заявок». Если вписать туда
адрес (например, Formspree), заказы будут приходить и на почту, и в WhatsApp.

## Каталог и прайс-лист

- Источник названий, весов и цен — прайс-листы поставщика (`tools/photo_src/client/документ*.jpg`, от 22.07.2026).
- Сборка каталога: `python tools/build_catalog.py` → `data/catalog.json`, затем
  `node tools/embed_catalog.cjs` (встраивает резервную копию в `assets/js/data.js` для работы без сервера).
- Фото заказчика приводятся к кадру 4:3 скриптом `python tools/client_photos.py`.

## Локальный запуск

Просто откройте `index.html` в браузере. Либо поднимите локальный сервер:

```
python -m http.server 8000
```

и зайдите на `http://localhost:8000`.
