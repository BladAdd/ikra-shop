Админ-панель

Управление каталогом, ценами, фото и настройками магазина.

Панель сохраняет изменения прямо в репозиторий сайта на GitHub. Нужен токен доступа — инструкция ниже.
Хранится только в этом браузере. Никуда не отправляется, кроме api.github.com.
Как получить токен (2 минуты)
  1. Откройте github.com/settings/personal-access-tokens/new
  2. Token name: ikra-admin
  3. Expiration: поставьте No expiration (или год)
  4. Repository access → Only select repositories → выберите ikra-shop
  5. Permissions → Repository permissions → Contents: Read and write
  6. Нажмите Generate token и скопируйте его сюда

Токен даёт доступ только к этому репозиторию. Никому его не передавайте.

Реквизиты

Оплата

Как покупатель платит за заказ.

Сейчас работает режим «по ссылке»: заказ приходит в WhatsApp, вы отправляете покупателю ссылку на оплату. Это рабочий вариант без регистрации в платёжном сервисе.

Способ приёма оплаты

Секретный ключ платёжного сервиса здесь указывать нельзя: он должен храниться только на сервере. Для приёма карт на сайте нужна серверная часть — это отдельная работа.

Приём заказов на почту (необязательно)

Если заполнить — заказы будут приходить и на почту, и в WhatsApp. Бесплатно заводится на formspree.io.
