# Публикация сервера (авторизация, онлайн-заказы, оплата)

Сайт сейчас на GitHub Pages — это **только статика**, у неё нет бэкенда. Поэтому
регистрация и вход не работают: браузер стучится в `/api/auth/register`, а Pages
отвечает `405`. Сервер написан и протестирован — его нужно один раз запустить
на любой платформе, которая умеет держать Node-процесс.

Готово к деплою: `Dockerfile` и `railway.json` уже в репозитории. Ниже — два пути.

---

## Вариант A. Railway (проще, есть бесплатный тир)

1. Зайдите на **https://railway.app** и войдите через GitHub.
2. «New Project» → «Deploy from GitHub repo» → выберите `BladAdd/ikra-shop`.
   Railway сам увидит `Dockerfile` и соберёт образ.
3. Откройте созданный сервис → вкладка **Variables** → добавьте:

   | Переменная | Значение |
   |---|---|
   | `NODE_ENV` | `production` |
   | `PORT` | `8080` |
   | `DB_PATH` | `/data/shop.db` |
   | `JWT_SECRET` | длинная случайная строка (см. ниже как сгенерировать) |
   | `APP_URL` | ссылка на этот сервис (Railway выдаст её после сборки) |
   | `FRONTEND_URL` | `https://bladadd.github.io/ikra-shop` |
   | `ADMIN_EMAILS` | ваша почта (получит доступ к админке) |
   | `YANDEX_CLIENT_ID` / `YANDEX_CLIENT_SECRET` | из кабинета oauth.yandex.ru |
   | `VK_CLIENT_ID` / `VK_CLIENT_SECRET` / `VK_SERVICE_TOKEN` | из кабинета id.vk.ru |
   | `MAX_WEBAPP_TOKEN` | токен чат-бота MAX |

   Сгенерировать секрет:
   ```
   node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
   ```
4. Вкладка **Settings → Volumes** → «Add Volume», mount path **`/data`**.
   Без тома база будет теряться при каждом перезапуске.
5. **Settings → Networking → Generate Domain** — получите адрес вида
   `https://ikra-shop-server.up.railway.app`.
6. Вернитесь в **Variables** и проверьте `APP_URL` — он должен совпадать с этим адресом.
7. Откройте в браузере `https://ваш-адрес/api/health` — должен вернуться JSON
   `{"ok":true,"oauth":{...}}`.

## Вариант B. Render

1. **https://render.com** → войти через GitHub → «New +» → **Web Service** → репозиторий `ikra-shop`.
2. Runtime: **Docker**. Render подхватит `Dockerfile`.
3. Environment: те же переменные, что в таблице выше; `DB_PATH=/var/data/shop.db`.
4. «Add Disk»: mount path `/var/data`, размер 1 GB.
5. После сборки скопируйте адрес `https://xxx.onrender.com` в `APP_URL`.

## Последний шаг: подключить сайт к серверу

Пока сайт не знает адрес API, кнопки входа остаются неактивными. Нужно прописать
одну строку перед подключением скриптов в `index.html` и `product.html`:

```html
<script>window.IKRA_API_URL = "https://ваш-адрес.up.railway.app";</script>
```

и пересобрать сайт (`npm run build:pages`) — либо сообщите мне адрес, я сделаю сам.

После этого заработают:
- регистрация и вход (почта/пароль, Яндекс, VK, MAX);
- «Мои заказы» в личном кабинете;
- сохранение заказов в базе;
- онлайн-оплата RollyPay (нужны `ROLLYPAY_API_KEY` и `ROLLYPAY_SIGNING_SECRET`).

## Что потребуется от провайдеров входа

После появления адреса сервера впишите в кабинетах:

- **Яндекс** (oauth.yandex.ru → ваше приложение): Redirect URI
  `https://ваш-адрес/api/auth/yandex/callback`
- **VK** (id.vk.ru → приложение): доверенный redirect
  `https://ваш-адрес/api/auth/vk/callback`
- **MAX**: URL мини-приложения `https://bladadd.github.io/ikra-shop/max-auth.html`

Подробности — в [НАСТРОЙКА-ВХОДА.md](НАСТРОЙКА-ВХОДА.md).

## Проверка, что всё живо

```bash
curl https://ваш-адрес/api/health
# ожидаем: {"ok":true,"oauth":{"yandex":true,"vk":true,"max":true,...}}
```

Реальный заказ: соберите корзину на сайте → оформите → заказ должен появиться
в админке во вкладке «Заказы».
